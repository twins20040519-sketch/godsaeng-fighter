# GODSAENG FIGHTER (갓생파이터)

하루를 알차게 보낸 기록으로 모르는 사람·친구와 겨루는 아케이드 스타일 갓생 배틀 앱.

## 파일
- `www/index.html` : 앱 본체 (실제 앱에 들어가는 화면)
- `갓생파이터.html` : 같은 화면의 보관용 사본 (더블클릭해서 브라우저로 보기)
- `capacitor.config.json` : 앱 이름 / 앱 ID 설정
- `package.json` : 프로젝트 정보

## 지금까지 만든 기능
- 오늘의 갓생 현황판: 4종목 인증 현황, 오늘 승점, 종목별 상태
- 종목 4개 (하루에 여러 개 가능, 종목마다 순위·코인 따로)
  - 새벽러: 기상 시각 인증
  - 책벌레: 책 제목 + 총 페이지 등록, 매일 몇 쪽까지 읽었는지 인증, 진행률 표시
  - 헬창: 타이머로 하루 운동 시간 누적 + 운동 인증 사진(필수)
  - 열공러: 카메라 라이브 켜진 동안만 공부 시간 누적
- 배틀 방식 3개: 친구방(코드 초대), 랜덤 1:1, 10인 난투
- 실시간 배틀 애니메이션 (펀치, 필살기, 화면 흔들림)
- 도트 캐릭터 8종, 코인으로 구매
- 연속 인증 스트릭 + 연속 보너스 코인
- 마이페이지: 종목별 전적, 색 링 달력
- 오늘 기록은 자정까지 기기에 저장

## 아직 연습용인 부분 (서버 필요)
